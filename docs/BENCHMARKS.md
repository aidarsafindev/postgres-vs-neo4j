Методология бенчмарка
Цель
Честно сравнить SQL и Cypher на одной задаче: поиск кратчайшего пути.

Что сравниваем
Вариант	Описание
SQL naive	Recursive CTE без pruning (как в первой версии)
SQL optimized	Recursive CTE с pruning по upper bound
pgRouting	Нативный Dijkstra на C в PostgreSQL
Neo4j	apoc.algo.dijkstra
Что НЕ сравниваем
Честно говорим, чего в бенчмарке нет:

❌ Materialized views в PostgreSQL

❌ Partitioning таблицы roads

❌ Кэширование результатов

❌ Кластер Neo4j (single-node)

❌ Реальные пробки (синтетические данные)

Вывод: цифры — нижняя граница для SQL и верхняя для Neo4j. Реальный разрыв может быть меньше. Но даже так — он на порядки.

Данные
Генератор использует одинаковый seed (42) для Neo4j и PostgreSQL

Одинаковое количество городов, дорог, складов

Одинаковые веса рёбер

Сверка: sql/verify.sql + docker/neo4j/verify.cypher

Малый	100	500	5

Большой	10 000	50 000	100

Метрики
Avg — среднее по 20 итерациям

Min — лучший результат

Max — худший результат

P95 — 95-й перцентиль

Speedup — отношение avg SQL к avg Neo4j

Замеры через time.monotonic() на стороне прокси — включает сетевой round-trip и парсинг JSON.

Как запустить
Малый граф (1000 городов)

docker-compose --profile generator run --rm generator
bash scripts/run-benchmark.sh

Большой граф (100 000 городов)

NUM_CITIES=100000 NUM_ROADS=500000 \
  docker-compose --profile generator run --rm generator
bash scripts/run-benchmark.sh

Интерпретация
Что означает разрыв
SQL naive vs SQL optimized — 3000× — показывает, насколько важен pruning

SQL optimized vs pgRouting — 200× — цена эмуляции графа в реляционной модели

pgRouting vs Neo4j — 4–5× — цена SQL-обвязки и round-trip

SQL naive vs Neo4j — 13 500× — итоговый разрыв в задаче

Воспроизводимость
Для честного сравнения:

Одинаковые данные — seed 42 в обоих движках

Одинаковое железо — оба в Docker на одной машине

Одинаковая метрика — время ответа прокси

Прогрев — первые 3 итерации отбрасываются

Изоляция — бенчмарк запускается отдельно от других нагрузок

Ограничения
Синтетические данные ≠ реальные пробки

Один узел ≠ кластер

20 итераций ≠ статистически значимая выборка

Время на маленьких графах — шум

Честный вывод: бенчмарк показывает порядок разрыва, а не точную цифру.
